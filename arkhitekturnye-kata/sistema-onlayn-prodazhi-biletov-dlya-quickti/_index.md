## Описание

Компания хочет создать внутреннюю систему бронирования переговорных комнат взамен таблицы в Excel

## Пользователи

-  Сотрудники (бронируют комнаты)

-  Администраторы офиса (управляют списком комнат)

## Требования

-  Сотрудник видит список свободных комнат на нужное время

-  Сотрудник бронирует комнату на определённый интервал

-  Бронирование в реальном времени, без двойных броней

-  Сотрудник может отменить своё бронирование

-  Администратор добавляет/убирает комнаты из системы

## Дополнительный контекст

-  Один офис, около 300 сотрудников

-  Пиковая нагрузка -- утро понедельника

-  Сроки сжатые, руководство хочет запустить систему уже через пару месяцев
