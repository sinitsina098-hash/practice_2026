## 🧩 2. Выбранный архитектурный стиль

**Стиль: монолит**

**Обоснование выбора** (3-4 предложения):

-  одна небольшая команда, для которой не требуется опыт работы с распределенными системами

-  приложение небольшое с ограниченным функционалом, не требуется много сценариев развития

-  отсутствие двойных броней, обеспечивается одной надежной БД

## 🚩 4. Главный риск выбранного решения

-  все хорошо для одного офиса, масштабироваться будет тяжело. Приложение простое и будет тормозить разработку и масштабировать

-  сроки сжатые, будет трудно проработать систему прав доступа. есть риск того, что сотрудники смогут менять чужие брони

## 🔀 5. Отвергнутая альтернатива

**Какой стиль рассматривали, но не выбрали: микросервисы**

**Почему отказались:**

-  слишком тяжело для маленькой команды

-  сжатые сроки

-  нагрузка не оправдывает сложность
