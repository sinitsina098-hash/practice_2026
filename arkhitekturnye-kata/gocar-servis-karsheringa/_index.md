## Описание

Сервис каршеринга хочет предоставить пользователям мобильное приложение для поиска, аренды и завершения поездки на автомобиле.

## Пользователи

-  Клиенты (арендуют автомобили)

-  Служба поддержки (обрабатывает обращения по проблемным поездкам)

## Требования

-  Клиент видит список свободных автомобилей рядом на карте

-  Клиент бронирует и открывает автомобиль через приложение

-  Клиент завершает поездку, автомобиль автоматически блокируется

-  Стоимость поездки рассчитывается автоматически по времени/км

-  Оплата списывается с привязанной карты после завершения поездки

## Дополнительный контекст

-  Сервис работает в одном городе, около 500 автомобилей

-  Пиковая нагрузка -- вечер пятницы и выходные

-  Инвесторы рассчитывают на кратный рост парка автомобилей в течение года
