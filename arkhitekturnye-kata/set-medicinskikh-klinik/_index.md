## Описание

Стартап создаёт платформу для поиска и записи к ветеринарам -- аналог медицинской системы бронирования, но для владельцев животных.

## Пользователи

-  Владельцы животных (ищут врача, записываются на приём)

-  Ветеринарные клиники (управляют расписанием врачей)

## Требования

-  Владелец ищет клинику по району и специализации врача

-  Владелец видит свободные слоты и записывается на приём

-  Владелец получает напоминание о визите

-  Владелец может отменить или перенести запись

-  Клиника управляет расписанием своих врачей

## Дополнительный контекст

-  Запуск в одном крупном городе, дальше -- по всей стране

-  Разные клиники используют разные внутренние системы учёта (legacy)

-  Бюджет на старте ограничен, инвестиции зависят от успеха пилота
