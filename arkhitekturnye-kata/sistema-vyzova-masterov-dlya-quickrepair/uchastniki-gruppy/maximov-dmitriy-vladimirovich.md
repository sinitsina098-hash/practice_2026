### 1\.2 Описание микросервиса

Микросервис обеспечивает следующую функциональность:

1. Регистрация пользователя приложения (логин пользователя и пароль)

2. Идентификация пользователя приложения (проверка корректности логина пользователя)

3. Аутентификация пользователя приложения (проверка корректности пароля)

4. Авторизация пользователя приложения (выдача доступа пользователя к приложению)

5. Удаление учетной записи пользователя (удаление данных пользователя из системы)
