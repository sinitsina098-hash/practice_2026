## Описание

Сервис позволяет пользователям обмениваться бумажными книгами друг с другом без денежных операций -- только через систему обмена.

## Пользователи

-  Пользователи (выставляют свои книги, ищут книги для обмена)

## Требования

-  Пользователь добавляет книгу в свой каталог «на обмен»

-  Пользователь ищет книгу по названию/автору среди других пользователей

-  Пользователь предлагает обмен (выбирает свою книгу взамен)

-  Другой пользователь подтверждает или отклоняет предложение обмена

-  После подтверждения пользователи обмениваются контактами для доставки

## Дополнительный контекст

-  Небольшой пилотный проект, команда -- 2 разработчика

-  Ожидается всего несколько тысяч пользователей в первый год

-  Бюджет минимальный, цель -- быстро проверить идею
